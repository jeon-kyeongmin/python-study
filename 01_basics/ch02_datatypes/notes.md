# 2장 자료형

프로그램의 기본이자 핵심 단위가 바로 자료형이다. 계산 프로그램을 만들려면 어떤 것을 계산할 것인지부터
알아야 하고, 데이터베이스 프로그램을 만들려면 어떤 자료를 저장할 것인지부터 알아야 하는 것처럼 기본 중의 기본이다.

숫자형, 문자형, 리스트, 튜플, 딕셔너리, 집합, 불 자료형등이 있다. 
변수(자료형의 값을 저장하는 공간)에 대해서도 알아본다.

## 2-1 숫자형 자료형

숫자형(number)은 숫자 형태로 이루어진 자료형이다. 1.정수, 2.실수, 3. 8진수, 16진수 등이 여기에 해당한다.
ex) 정수(123, -345, 0), 실수(123.45, -1234.5, 3.4e10), 8진수(0o34), 16진수(0x2A)

이제 숫자를 파이썬에서 어떻게 만들고 사용하는지 알아보자.

   1. 정수형

    정수형(integer)은 정수(양의 정수, 음의 정수, 0)를 뜻하는 자료형이다.

    ```python
    a=123
    a=-178
    a=0
    ```

   2. 실수형

    실수형(floating-point)은 소수점이 포함된 숫자를 말한다. 

    ```python
    a=1.2
    a=-3.45
    a=4.24E10
    a=4.24e-10
    ```

   3. 8진수와 16진수

    8진수(octal)는 0o 또는 0O(숫자 0 + 알파벳 소문자 o 또는 대문자 O)로 시작한다.
    16진수(hexadecimal)는 0x로 시작한다.


### 숫자형을 활용하기 위한 연산자

   1. 사칙연산 (+,-,*,/)

    ```python
    a, b = 3, 4
    덧셈 : a+b >>> 7
    뺄셈 : a-b >>> -1
    곱셈 : a*b >>> 12
    나눗셈 : a/b >>> 0.75
    ```

   2. 몫/나머지 (//,%)

    ```python
    나머지 : 7%3 >>> 1
    나머지 : 3%7 >>> 3
    몫 : 7//4 >>> 1
    나눗셈 : 7/4 >>> 1.75
    ```

   3. 제곱 (**)

    ```python
    3**4 >>> 81
    ```

   4. 복합 연산자 (+=, -=, *=, /=, //=, %=, **=)

    ```python
    a = a + 1  >>>  a += 1
    a = a - 2  >>>  a -= 2
    a = a * 2  >>>  a *= 2
    a = a / 3  >>>  a /= 3
    a = a // 4  >>>  a //= 4
    a = a % 3  >>>  a %= 3
    a = a ** 3  >>>  a **= 3
    ```


## 2-2 문자형 자료형

python에서 문쟈열을 만드는 방법은 총 4가지이다. 
-> 큰따옴표, 작은따옴표, 큰따옴표 3개씩, 작은따옴표 3개씩

```python
"Hello World"
'Python is fun'
"""Life is too short, You need python"""
'''Life is too short, You need python'''
```

### 문자열 안에 작은따옴표나 큰따옴표를 포함시키고 싶을 때

   1. 문자열에 작은따옴표 포함하기 -> 큰따옴표로 둘러싸기
   >>> food = "Python's favorite food is perl"

   -> 이때 만약 큰따옴표가 아닌 작은따옴표로 둘더싸면 SyntaxError 발생

   2. 문자열에 큰따옴표 포함하기 -> 작은따옴표로 둘러싸기
   >>> say = '"Python is very easy." he says.'

   -> 결국 포함하고 싶은 기호와 다른 기호로 둘러싸기

   3. 역슬레시(\)를 사용해서 작은따옴표와 큰따옴표를 문자열에 포함하기
   >>> food = 'Python\'s favorite food is perl'
   >>> say = "\"Python is very easy.\" he says."

   -> 역슬레쉬 뒤의 작은따옴표나 큰따옴표는 문자열을 둘러싸는 기호가 아니라 문자 그자체 의미.


### 여러 줄인 문자열을 변수에 대입하고 싶을 때 

   다음과 같은 여러 줄의 문자열을 변수에 대입하려면 어떻게 해야 할까?
   ------------------------
   Life is too short
   You need python
   ------------------------

   1. 줄을 바꾸기 위한 이스케이프 코드(\n) 삽입하기
   >>> multiline = "Life is too short\nYou need python"

   -> 이 방법은 읽기가 불편하고 줄이 길어지는 단점이 있다. 

   2. 연속된 작은따옴표 3개 또는 큰따옴표 3개 사용하기
   >>> multiline='''
   >>> Life is too short
   >>> You need python
   >>> '''

   -> 1번 방법의 단점을 극복, 출력하려면 print(multline)


### 이스케이프 코드란?

   이스케이프(escape) 코드란 프로그래밍 할 때 사용할 수 있도록 미리 정의해둔 '문자 조합'이다.
   주로 출력물을 보기 좋게 정렬하는 용도로 사용한다. 많이 사용되는 예 5개만 보자.

   - \n : 문자열 안에서 줄을 바꿀 때 사용
   - \t : 문자열 사이에 tap 간격을 줄 때 사용
   - \\ :  \을 그대로 표현할 때 사용
   - \' , \"  : 작은따옴표, 큰따옴표 그대로 표현할 때 사용


### 문자열 연산하기

   파이썬에서는 문자열을 더하거나 곱할 수 있다. (1,2)
   길이를 구할 수 있고 문자나 단어를 뽑아내는 것도 가능하다. (3,4)  

   1. 문자열 더하기 (연결)
   >>> head = "Python"
   >>> tail = " is fun!"
   >>> head + tail
   'Python is fun!'

   2. 문자열 곱하기 (반복)
   >>> a = "python"
   >>> a * 2
   'pythonpython'

   *응용 : 프로그램 제목 표시
   ```python
   print("=" * 50)
   print("My Program")
   print("=" * 50)
   ```

   3. 문자열 길이 구하기 (len함수 사용)
   >>> a = "Life is too short"
   >>> len(a)
   17 (문자열의 길이에는 공백 문자도 포함!)

   4. 문자열 인덱싱과 슬라이싱
   >>> a = "Life is too short, You need Python"

   - 인덱싱 (문자 뽑아내기)

   머리 속으로 해당 문자열에 번호를 메겨보아라.
   L부터 시작하고 번호는 0부터 메긴다. 그리고 공백을 포함한다. 

   우리는 a[번호]를 통해 특정한 값을 뽑아낼수 있는데 이러한 작업이 '인덱싱'이다. 
   >>> a = "Life is too short, You need Python"
   >>> a[3]
   'e'

   여기서 a[3]이라는 것은 a라는 문자열의 네 번째 문자이다. 0부터 시작하기 때문이다.
   따라서 a[0]:'L', a[1]:'i', a[2]:'f', a[3]:'e', a[4]:' ', ... 처럼 메길 수 있다.
   이건 앞에서 부터 센 것이고, 뒤에서 부터 셀 수도 있다. -(빼기) 기호를 붙이면 된다. 

   a[-1]는 뒤에서부터 세어 첫 번째가 뒤는 문자로 제일 끝 문자이다. 
   따라서 a[-1]:'n', a[-2]:'o', a[-5]:'y' 처럼 메길 수 있다. 

   - 슬라이싱 (단어 뽑아내기)

   인덱싱에서 문자 한 개를 뽑아내었다면 슬라이싱에서는 단어를 뽑아밸 수 있다.
   >>> a = "Life is too short, You need Python"
   >>> a[0:4]    
   'Life'

   a[시작번호:끝번호]로 단어를 뽑아내는데 끝번호에 해당하는 문자는 포함하지 않는다. 
   -> 범위로 나타내면 "시작번호 ~ 끝번호 - 1"까지 뽑아내는 것이다. 

   그리고 시작번호나 끝번호는 생략이 가능하다.
   >>> a[19:]                   -> 시작번호에서 끝까지 뽑아낸다.
   'You need Python'
   >>> a[:17]                   -> 처음부터 끝번호까지 뽑아낸다.
   'Life is too short'
   >>> a[:]                     -> 문자열의 처음부터 끝까지 뽑하낸다.
   'Life is too short, You need Python'

   슬라이싱에서도 -(빼기)기호를 사용할 수 있다. 
   >>> a[19:-7]
   'You need'

   -> a[19:-7]은 a[19]에서 a[-8]까지를 의미한다. 이때에도 a[-7]은 포함하지 않는다.

   *예제1 : 슬라이싱으로 문자열 나누기
   ```python
   >>> a = "20230331Rainy"
   >>> year = a[:4]
   >>> day = a[4:8]
   >>> weather = a[8:]
   >>> year
   '2023'
   >>> day
   '0331'
   >>> weather
   'Rainy'
   ```

   *예제2 : pithon 문자열을 python으로 바꾸려면?
   >>> a = "Pithon"
   >>> a[1]
   'i'
   >>> a[1] = 'y'

   이렇게 하면 오류가 발생한다. 문자열의 요솟값은 바꿀 수 없는 값이기 때문이다. 
   하지만 슬라이싱 기법을 사용하면 pithon 문자열을 python으로 바꿀 수 있다.
   >>> a = "Pithon"
   >>> a[:1]
   'P'
   >>> a[2:]
   'thon'
   >>> a[:1] + 'y' + a[2:]    (연결)
   'Python'

### 문자열 포매팅

문자열 포매팅(string formatting)은 문자열 안의 특정한 값을 바꿔야 할 경우에 이것을 가능하게 한다.

1. 숫자 바로 대입
>>> "I eat %d apples." % 3
'I eat 3 apples.'

2. 문자열 바로 대입
>>> "I eat %s apples." % "five"
'I eat five apples.'

3. 숫자 값을 나타내는 변수로 대입
>>> number = 3
>>> "I eat %d apples." % number
'I eat 3 apples.'
